      Alerts

      An alert reaches the stations that share a circle's keyword at once, as a broadcast: no call, no session. There it sounds until its operator answers. Anyone listening can read it; only the circle can make one. About 16 seconds on the air with Aether.

      Circles

      A circle is the stations whose operators typed the same keyword. Tell the keyword to the others by voice or in person, never on the air, and read your checks to each other: the same check means the same keyword.

                  For what no job does, a terminal on the server: this computer's own SSH, with the key in its own agent.               Setting up the key, once
              
                  On Windows, in PowerShell: ssh-keygen -t ed25519, then put the line in %USERPROFILE%\.ssh\id_ed25519.pub in the server's /root/.ssh/authorized_keys (your hosting provider's panel has a place for SSH keys). With a passphrase, Start-Service ssh-agent and ssh-add keep it unlocked while you are logged in.
                  
            
                  
            
                  
              
            
                  
            
          
                  
          
                  
            
                  Backups
                  
            
                  Each night the server keeps a backup of the post office beside itself, the last seven, and one of the mail server's mailboxes, the last three. A backup that stays on the server is lost with it: keep them on a computer of yours too. Each holds the post office's key, and the newest mailboxes go with it.
